# AKSNOVA Architecture Guidelines

- Keep placement-company artwork from verified sources or user-supplied reference crops in a shared company-logo map with hosted asset pointers and a text fallback, so company identities remain consistent and resilient.
- Preserve static-first Astro architecture: marketing and public content pages must remain pre-rendered static HTML with minimal client-side hydration.
- Maintain strict SEO validation across all pages (canonical URLs, Open Graph metadata, semantic HTML, and JSON-LD schema markup).
