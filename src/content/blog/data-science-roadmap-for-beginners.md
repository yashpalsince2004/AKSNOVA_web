Data science sits at the intersection of business intelligence, computer science, and statistics. It transforms raw business logs into actionable strategic decisions.

## What is Data Science?

Every digital transaction, app interaction, and customer click leaves behind data footprints. Data scientists collect, clean, model, and extract actionable insights from this information.

## Stage 1: Data extraction with SQL

Before running machine learning models, you must know how to retrieve records efficiently from relational databases:

```sql
SELECT
    city,
    COUNT(*) AS total_students,
    AVG(placement_readiness_score) AS avg_readiness
FROM student_enrolments
WHERE status = 'Active'
GROUP BY city
ORDER BY total_students DESC;
```

## Stage 2: Exploratory Data Analysis (EDA)

Using Python tools like **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn**:
- Identify missing values and impute them logically.
- Detect statistical outliers and skewed distributions.
- Compute correlation matrices to see how variables interact.

## Stage 3: Supervised Machine Learning

Start by mastering supervised learning algorithms:
- **Regression:** Predict continuous numbers such as housing prices, salary expectations, or sales volume.
- **Classification:** Predict categorical classes such as loan approval, spam detection, or customer churn.

Always evaluate your models using metrics like Mean Absolute Error (MAE), Precision, Recall, and F1-Score rather than relying on raw accuracy alone.
